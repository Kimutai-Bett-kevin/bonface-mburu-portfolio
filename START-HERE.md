# Bonface Mburu Portfolio

Complete current source code, photos, office-books and graduation imagery, charts, content, styles, configuration, dependency lockfile and tests. Original supplied portraits and mockup are included in original-uploads.

## Run locally

Install Bun from https://bun.sh, open a terminal in this folder, then run:

```sh
bun install
bun run dev
```

Open the local address printed in your terminal.

Other commands: `bun run test`, `bun run build`, `bun run preview`.

Portrait files are included under public/__l5e/assets-v1 so existing image pointers work locally without Lovable hosting. Other images are in src/assets.

Dependencies, generated output, repository metadata and private workspace files are intentionally excluded. Install dependencies as shown above.

CV and certificate downloads still await the owner’s documents.
